PlayBridge local control

Programs on this PC can press PlayBridge's buttons through these addresses: a Stream Deck, Touch Portal, a hotkey program or a script. Each one starts with this PC's secret, so keep them to yourself. Another device cannot reach them.

Commands

Stream Deck

Add a Website action from the System group, paste a command's address, and tick GET request in background, so no browser opens. Touch Portal and hotkey programs: send an HTTP GET or POST to the same address.

OBS overlay

Browser source

In OBS, add a Browser source with this address, 1920 × 1080. It shows the game, its frame rate and temperatures, REC and LIVE, the speedrun timer and each trophy as it unlocks. Add ?chat=1 for the Twitch chat, or ?scale=1.5 for a larger one.
